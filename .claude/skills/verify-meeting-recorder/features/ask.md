# 질문으로 찾기

오른쪽 아래 둥근 버튼은 모든 화면에 있다. 누르면 채팅 창, 말로 물으면 본체가 회의들을 찾아 회의 화면에 질문 탭을 만든다. 조건 칩(최근 몇 개·기간)은 AND, 질문 속 기간과 기간 칩이 안 겹치면 찾지 않고 경고한다. 다른 화면에 있을 때 끝나면 버튼 옆 알림과 뱃지, `보기`로 질문 탭.

## Sub-features

- `ask-start` 질문 보내기(`찾기` 버튼·Enter).
- `ask-chips` 최근 몇 개(숫자만)·기간(누르면 최근 7일).
- `ask-conflict` 기간 충돌 경고 → `기간 칩 빼고 질문 날짜로 찾기`·`질문 고치기`.
- `ask-notify` 끝나면 알림·뱃지 → `보기`.
- `ask-tab` 질문 탭: 주제로 다룬 회의 / 잠깐 언급된 회의, 줄마다 이유.
- `ask-fail` 실패 문구(시간 초과·로그인 풀림)와 `다시 찾기`, 멈추기.

## How to get to it (user POV)

- 어느 화면에서든 오른쪽 아래 `질문으로 찾기` 버튼 (열려 있으면 `질문 창 닫기`).

## Driving it with drive.js

Preconditions:

- `"env": { "STUB_MANY": "3", "STUB_ASK_MS": "300" }`. 가짜 엔진: 결과는 첫 회의(주로 다룸)·둘째(잠깐 언급).

- **보내기.** `{ "click": "질문으로 찾기", "role": "button" }`, `{ "fill": "예: 작년 2월", "value": "배포 얘기한 회의" }`, `{ "click": "찾기", "role": "button", "exact": true }` → `{ "expect": { "called": "askStart", "args": ["배포 얘기한 회의"] } }`.
- **다른 화면에서 알림.** `{ "click": "질문 창 닫기", "role": "button" }`, `{ "go": "#stats" }`, `{ "until": "건을 찾았습니다" }`, `{ "click": "보기", "role": "button" }`.
- **질문 탭.** `{ "expect": { "hash": "#meetings" } }`, `주제로 다룬 회의`, 이유 `배포 일정을 정한 회의`가 보임.
- **실패.** 질문에 `로그인`을 넣으면 `Claude Code 로그인이 풀렸습니다`, `실패`를 넣으면 `답이 너무 늦어 멈췄습니다`.
- **증거.** 흐름 `journeys/ask.json`.

## Gotchas

- 채팅 창이 열려 있으면 끝 알림 대신 채팅에 결과가 나온다. 알림을 보려면 창을 닫는다.
- `찾기`는 다른 버튼 이름에도 들어간다 → `exact: true`.
- 진짜 엔진(색인·LLM)은 이 도구로 증명되지 않는다 → `ask-engine-check.js`.
