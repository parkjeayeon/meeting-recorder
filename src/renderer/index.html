다듬기

"음, 3시에, 아니 4시에" → "4시에". 군말을 지우고 문장을 정리합니다. 회의록과 정리본도 같은 계정으로 만듭니다.

입력하기 전에 다듬기끄면 들린 그대로 입력합니다.
사용할 계정로그인된 Claude Code·Codex 구독을 먼저 씁니다. 없으면 API 키를 씁니다.

회의

회의는 위쪽 회의 녹음 버튼이나 독·메뉴바로 시작하고 멈춥니다. fn은 받아쓰기 전용입니다.

끝나면 회의록 만들기Whisper large-v3로 녹취한 뒤 요약·결정 사항·할 일을 정리합니다. 2시간 회의는 약 20분 걸립니다.
화자 구분누가 말했는지 구분합니다 (pyannote, 이 Mac 안에서 처리).
화상 회의 상대방 소리시스템 오디오를 따로 녹음합니다. 대면 회의에서는 꺼 두세요.

엔진

음성 인식과 화자 구분에 필요한 프로그램과 모델입니다. 화자 구분은 샌드박스 안에서 앱 폴더에만 설치되고, 실행할 때는 네트워크가 막혀 회의 녹음이 밖으로 나가지 않습니다.

계정·토큰
